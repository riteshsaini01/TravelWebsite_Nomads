# Nomads – AI Trip Planner 🌍✈️  

Nomads is an **AI-powered travel planner and destination explorer** built with **React + Vite**, designed to help users discover destinations, create personalized itineraries, and plan trips effortlessly.  

The project leverages **Google Gemini AI** for smart travel suggestions and **Firebase** for authentication and real-time storage, ensuring a smooth and engaging user experience.  

---

## 🔑 Features  
- **AI Trip Planner** – Generate personalized travel itineraries with destination, activities, and timeline recommendations.  
- **Destination Explorer** – Discover new places with intelligent AI-driven suggestions.  
- **User Authentication** – Secure login with Firebase.  
- **Real-Time Storage** – Save and manage your travel plans on the cloud.  
- **Responsive UI** – Optimized for seamless use across devices.
